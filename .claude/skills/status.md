# 项目状态

查看项目当前的开发进度和状态。

## 使用方式

`/status`

## 执行步骤

1. 读取 docs/MODULES_AND_TESTS.md 获取模块列表
2. 逐个检查每个模块的源文件是否存在
3. 检查每个模块的测试文件是否存在
4. 运行 `pnpm test --reporter=verbose 2>&1 | tail -30` 获取测试状态
5. 运行 `pnpm build 2>&1 | tail -10` 确认构建状态
6. 输出进度表格：

```
| 模块 | 源码 | 测试 | 状态 |
|------|------|------|------|
| M01 项目基础设施 | ✅ | ✅ | 完成 |
| M02 API 客户端 | ✅ | ❌ | 缺测试 |
| M03 消息与类型 | ❌ | ❌ | 未开始 |
```

7. 给出下一步建议（应该实现哪个模块）

## 约束

- 状态判断基于文件是否存在 + 测试是否通过
- 建议按依赖顺序推荐下一个模块
