description: 对指定 ds-code 模块或文件做行为保持的重构
allowed-tools:
  - Read
  - Edit
  - Write
  - Bash
  - Grep
  - Glob
---

用于改善结构、命名、重复代码或类型设计，同时保持外部行为不变。

执行流程：
1. 明确重构目标、动机和行为边界；会改变外部接口或用户体验时先等待确认。
2. 阅读相关源码和测试；覆盖不足且风险较高时先补行为测试。
3. 小步修改，删除确定无用的代码，避免为假设的未来需求抽象。
4. 运行目标测试、相关测试和 `pnpm build`。
5. 用 `git diff --stat` 检查范围，汇报收益、验证结果和风险。

约束：不改变外部行为；不做范围外改动；不引入无必要抽象；不自动提交。
