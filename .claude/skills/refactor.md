# 重构

对指定模块或文件进行重构。

## 使用方式

`/refactor` 然后描述重构目标

## 执行步骤

1. 理解重构目标和动机
2. 读取相关源码，理解当前实现
3. 检查该代码的测试覆盖情况
4. 如果测试不足，先补充测试（确保重构不破坏行为）
5. 执行重构：
   - 小步修改，每步确认编译通过
   - 保持对外接口不变（除非重构目标就是改接口）
6. 运行 `pnpm build` 确认编译通过
7. 运行 `pnpm test` 确认所有测试通过
8. 用 `git diff --stat` 展示改动范围
9. 简要说明重构内容和收益

## 约束

- 重构不改变外部行为（除非明确要求）
- 先有测试再重构
- 不做超出要求范围的改动
- 如果重构影响面大，先说明方案等确认
