---
name: review
description: 审查当前分支、未提交改动或最新提交的代码质量与风险
allowed-tools:
  - Read
  - Bash
  - Grep
  - Glob
---

用于代码审查，不主动修改文件。

执行流程：
1. 查看当前 `git status` 和 `git diff`；无未提交改动时审查最新提交或用户指定范围。
2. 只审查本次改动涉及的代码，必要时阅读相关上下文。
3. 重点检查正确性、安全性、一致性、性能、错误处理、类型安全和测试缺口。
4. 必要时运行 `pnpm build`、`pnpm test` 或更小范围测试。
5. 按严重程度输出问题，包含 `file_path:line_number`、影响和具体修复建议。

约束：没有问题要明确说明；不要为了审查做无关探索；除非用户要求修复，否则不修改代码。
