用于实现计划中的模块、补齐未完成能力或完成明确的新功能。

执行流程：
1. 读取与需求直接相关的文档；不要默认读取 `docs/PROJECT_PLAN.md`，除非用户按模块编号或计划项要求实现。
2. 阅读相关源码和测试，确认现状、缺口、依赖和完成标准。
3. 对多文件或存在多种实现路线的改动，先说明方案并等待确认。
4. 按现有风格做最小实现，必要时补测试；不要引入范围外依赖或无关重构。
5. 运行相关测试和 `pnpm build`。
6. 汇报变更文件、验证结果和遗留问题。
7. 更新相关文档

约束：遵循 `AGENTS.md`；接口与当前代码和相关文档一致；不自动提交。
